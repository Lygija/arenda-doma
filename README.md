# Гостевой дом Виталины

Мобильный лендинг гостевого дома в Калининграде.

## Подтверждённые данные

- Калининград
- 4 комнаты
- 126 м²
- исходное объявление: https://www.avito.ru/kaliningrad/doma_dachi_kottedzhi/4-k._dom_126_m_7487123572

На первом этапе сайт намеренно не содержит неподтверждённых цены, адреса, удобств или фотографий. Avito ограничивает автоматическое чтение карточки, поэтому реальные фотографии и полный текст объявления нужно добавить после получения исходных материалов.

## Структура

- `index.html` — страница сайта
- `styles.css` — адаптивный дизайн
- `script.js` — лёгкие анимации появления
- `.github/workflows/pages.yml` — публикация через GitHub Pages

## GitHub Pages

Workflow подготовлен для автоматического деплоя из `main`. Если Pages ещё не включён для репозитория, один раз выберите в GitHub: **Settings → Pages → Build and deployment → Source → GitHub Actions**.
